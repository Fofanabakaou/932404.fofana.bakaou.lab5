# Лабораторная работа №5 — DOM и взаимодействие с элементами страницы

Вариант 20 — Футуролог и концепт-художник (прогнозы с вероятностью)

## Описание
Интерактивная секция "Прогнозы с вероятностью": добавление и удаление карточек
прогнозов через DOM API, переключение темы (светлая/тёмная), скрытие/показ блока.
Все действия сохраняются в localStorage и восстанавливаются при перезагрузке.

## Реализовано
- Поиск элементов: getElementById
- DOM-манипуляции: createElement, appendChild, remove(), classList
- Обработка ошибок: проверка существования элементов перед манипуляциями
- Сохранение состояния в localStorage (прогнозы и выбранная тема)
